# RollABall

## Project Description

**RollABall** is a solo 3D Unity game starring an asteroid in space that must navigate obstacles and collect nearby stars to win. The game requires player coordination as they move through the level, avoid moving obstacles, and dodge enemy shooters.

## Repository Contents

This repository includes the Unity project folders needed to preserve and reopen the project:

- `Assets/` - Game scripts, scenes, prefabs, materials, UI, and other Unity assets
- `Packages/` - Unity package dependencies
- `ProjectSettings/` - Project-wide Unity settings
- `UserSettings/` - User-specific Unity editor settings from the original project

## Running the Project

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add project from disk**.
4. Choose the root folder of this repository.
5. Open the project with a compatible Unity version.
6. Open the main scene from the `Assets/` folder.
7. Press **Play** in the Unity Editor.

## Notes

This project was preserved from the original Unity project folders. If Unity asks to upgrade the project version, make a backup copy before upgrading.
